Bookmark Manager

智能书签管理工具 · 一键清理失效链接

功能特性

📊

书签总览

清晰展示所有书签统计，包括总数、有效数、无效数和文件夹数量

🔍

智能扫描

自动检测失效链接，支持标准扫描和快速扫描两种模式

🧹

一键清理

批量删除无效书签，轻松整理您的书签收藏

安装指南

  1. 打开 Chrome 浏览器，访问 chrome://extensions
  2. 开启右上角的「开发者模式」开关
  3. 点击「加载已解压的扩展程序」按钮
  4. 选择本项目的文件夹
  5. 扩展程序将自动加载到您的浏览器
📊 打开书签管理器 🔍 传统管理器
